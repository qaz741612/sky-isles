# Checkpoint B — same-source Blender outputs saved

Final editable Blender and runtime GLB are saved. Eight Cycles CPU / 48 sample renders (six views plus workshop and greenhouse details) use the exact .blend SHA256 recorded in blender/render-record.json; six-views.png is a contact sheet of those six renders. reference-comparison.png compares the supplied V2.2 design board with the Blender refinement, with no generated AI images.

The reference geometry and source ZIP contents are retained. The main workshop, three sawteeth/PV, curved greenhouse, exhibition pavilion and plaza are preserved. Changes are wall construction behind glazing, low-cost bevels, clearer glass/materials, door hardware, geometric short signs and two small planter clearance repairs. No other island art was changed. This is submitted for human art review, not a declaration of art acceptance.

The Blender-only asset excludes existing game-owned route stubs, perimeter guard and original mushroom. Actual game screenshots include these retained/generated world systems separately. Workshop and greenhouse remain closed exhibits with usable exterior approaches; no NPC implemented.

Blender in this environment has no OpenImageDenoise support; final renders use direct CPU samples without denoising. Earlier failed/outdated rendering attempts were not included as final images. Mobile porch camera review found the inherited near-head clamp; a C-only runtime fallback is being verified before final game delivery.
