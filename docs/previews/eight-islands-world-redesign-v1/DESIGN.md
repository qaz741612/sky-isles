# 八島建築、景觀與安全空間紀錄

基礎：V4 `08e70ce0247c1421aedf72447e56c276d4d50e89`。八島一起重製，沒有另建第二套運行場景。各項構築皆為政策主題空間示意，不是核定或完工工程；正式政策 JSON 沒有改寫。

## 共用空間與尺度

八島半徑統一 9，僅改 `src/data/yuan-plan.json` 的島半徑及修訂註記，再執行 `npm run generate:yuan`。所有中心座標、22 段 Bezier／直線、4.8 路寬、B 配置壓縮結果均保留。擴島後，既有短筆端 T5（生活館島）與 T7（公所島）的中心落入新版島面內；原曲線不動，露出外緣與橋口由聯集重新處理，沒有另加連接路段，詳見 [筆端交會稽核](expanded-tip-audit.json)。角色、風鈴、蘑菇、出生點及互動尺度沒有隨島面放大。

新增 `src/data/island-places.json` 集中管理主量體、庭院、鋪面輪廓、樹群、座椅、連續水路及八處未實作 NPC 預留資料。這些是手工設計的位置，沒有再使用尋找空格、逐一塞模型的配置器。建築的窗框、屋簷、柱、玻璃、基座、樹木及座椅由 `place-kit.js` 共用；各島的組合與輪廓不同。具體幾何構造仍在各場所建構函式中，後續精修可繼續參數化。NPC 只有站位、面向、停點及建議互動距離資料，沒有角色或對話系統；資料含現有實體邊界淨距，未宣稱驗證未製作 NPC 的實際對話鏡頭。

生成器將固定路網的真實路面帶裁切到新版島面，產生島內穿行鋪面；抵達橋口接續同色路面，停留庭院另有較淺鋪面與薄收邊。主要通行帶保留，留白用於穿行、停留與未來 NPC 接近，沒有用模型填滿島面。

## 安全與碰撞

- 由新版「島面＋全部路面＋原路口平台」做平面聯集；只取聯集外邊界。八島各自得到自己的暴露邊緣，橋口、重疊區與交通島南側共享口沒有內欄。
- 橋邊為灰青細柱／通透橫桿；島緣為淺石低牆與細上欄，配合各島內側植栽。沒有整圈複製舊紫色密集木格柵，也沒有用花草取代碰撞。
- 可見防護與水平阻擋使用同一組中心線；沿用角色半徑 0.33 與護欄碰撞厚度 0.16，保留小幅安全餘裕。
- 靜態美術合批、地面碰撞、水平牆柱阻擋、相機障礙與政策選取分開。樹冠、文字、格柵與所有裝飾沒有一概加入地面／相機射線。
- 一般行走的外緣防護與刻意跳躍分開：沿用跳躍能力時，仍可刻意越過欄頂或低水牆；跌落回到現有最近安全檢查點。本輪沒有改成不可越界的封閉世界。

## 光影與效能取捨

沿用方向光、半球光及四階 toon 材質；屋頂、窗框和屋簷有實際厚度。樹下／部分門廊使用共用 64×64 程式生成的柔邊接地陰影，每島合批，沒有外部貼圖、新即時燈源、昂貴後製或每幀重造靜態建築。這不是完整動態投影陰影，日照方向與接地陰影不是物理模擬。

每島保留獨立合批與剔除；路面和橋邊沿用既有分區結構。新增相機查詢在載入後建立靜態空間索引，只沿目標至相機附近的格子檢查明確牆／屋頂殼體，保留既有 orbit、zoom 與回復跟隨方式。人工仍需確認近屋簷、葉片及極端縮放時的舒適度。
