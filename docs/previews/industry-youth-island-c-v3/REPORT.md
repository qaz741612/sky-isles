- **溫室**：獨立完整弧形鋼拱、縱向構件、玻璃分格、端面、種植床、葉群／莖及基腳。南端門前有可達停留區，不開放室內玩法。

第一輪真實模型及輸出保存在 `iteration-1/`，自查指出工坊高帶未封完整、青年屋頂高差被原大板遮住、溫室幼苗太像方塊。第二輪已補完整端面、重做真實高低屋面、以葉群與莖替換方塊苗。最終六視圖與三個細節圖均來自同一份 .blend。

第一輪 hero 曾採西北側，最終 hero 採東南側以看清 PV 與雙引擎；相機紀錄完整保留，**不將不同方位稱作同機位前後比較**。正式 V2.2／V3 比較另以舊工程唯讀重渲染，hero 和俯視使用相同位置、正交尺度及 1000×800 尺寸。

## 碰撞與玩家鏡頭

地面、矮平台上表面、牆／柱／門、屋面、頭部限制與相機代理分離。保留原共用載入與物理，不將全 GLB 一律當地面。三棟建築室內保持關閉，玩家可到各門前與公共區。

本輪檢查發現舊代理將部分檐口當成可站屋面，並把 PV 片當成側向障礙。已改用明確屋面構件名與向上表面；PV 上表面及溫室拱肋可正確承接刻意跳躍。新測試以**實際可見 GLB**垂直射線對照真正 Player 的落地高度，避免只驗證代理本身。舊泛用屋頂測試改為跨同島所有碰撞分塊取最近命中，沒有移除測項。

第一輪全路線測試在工坊門廊某個 yaw 發現鏡頭太近；手機圖也顯示近處柱體佔據畫面。C 專屬避障因此較早尋找清楚的公共空間視線，並擴展可選側向角度；不修改玩家原生 orbit、zoom、速度或其他島專屬避障。新增完整旋轉與實體遮擋射線測試。長時間持續旋轉舒適度仍待人工操作。

材料比較採真正 GLTFLoader 所用材質；舊 .blend 報告的 39 包含未使用材料庫，實際舊 GLB 為 33，新版實際 GLB 為 29，沒有將兩種口徑混比。

**未驗證／仍待人工確認：**真實手機 GPU FPS、熱度、記憶體峰值、公網延遲、長時間單手舒適度；玻璃排序／反光、與安心生養的材質協調、植栽層次、側背面美術、近屋簷相機轉向手感及苑字主觀辨識。手機直式預設畫面不能一次包含整座園區，須正常旋轉或切全景，未以 QA 拉遠畫面替代。

已知中等視覺限制：手機工坊門廊貼近柱位時，角色一側仍可能被柱緣局部遮擋；已修正先前整個直式畫面幾乎被近柱佔滿的問題，但不能保證任意貼牆角度都完整看見全身，仍需實機旋轉／接近操作驗收。這不影響測試中通行或 NPC 預留區接近，截圖如實保留。

實作是依 V3 量體深化的 low-poly 可玩場景，仍不是寫實建築或人工美術通過的宣告。三棟室內不開放、沒有 NPC 對話，均屬本輪界線。既有 MIT／第三方聲明保留；本輪未使用未授權外部素材。

## 重建、保存與發布界線

先用含 numpy/trimesh/shapely/Pillow 的 Python 執行 `scripts/industry/prepare_c_v3.py`，再用 Blender 4.3 執行 `scripts/blender/build_industry_c.py -- --v3 --render`。後者打開原 V2.2 工程，將原構件留作隱藏 archive，新構件可編輯；不覆寫原始 V2.2 工程。`--pass1` 可重現第一輪設計。正式原地形不變，**無須重跑苑字生成器**。

完成建置可用 `npm run dev -- --host 0.0.0.0 --port 4233` 開啟工作區預覽。本工作階段在 4233 提供最終 production-build 本機預覽，這不是公開部署 URL。
