## 幾何、渲染及載入成本

新增景觀本身 83,139 三角面、72 個可見批次；相對合批前的 116 批減少約 38%。含橋面與外護欄變化，整個橋群由 50,381 → 138,024 幾何三角面，差 87,643。按 64 世界單位區域剔除，共用幾何及實例化；每幀沒有重建靜態景觀。

景觀衍生資料 192,586 bytes，gzip 75,402 bytes；沒有額外貼圖、GLB 或新依賴。CPU 欄位是景觀幾何建構計時，不包含全部下載、JS 解析、GPU 完成或真正首次可操作時間。
