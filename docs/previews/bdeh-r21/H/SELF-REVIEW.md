# H｜展頁式未來學習中心 R21 自主美術審查

這是工程與製作者自查紀錄，不是使用者美術批准。正式模型是本目錄 `blender/` 與 `docs/design/bdeh-r21/H/H-r21.blend`；`iteration-*` 是保留的歷史／失敗證據。

## 第一輪：量體與公共空間

保留兩翼閱讀／探索量體、展頁屋頂、中央連接與戶外階梯論壇。第一輪發現頁形屋頂下的側端構件、階梯立面及樹冠尺度不足。

修正：補真實高窗玻璃、框料、斜撐與頁形屋頂接點；論壇五階改成完整實體支承。試渲染抓到舊階梯上蓋與新立面重疊的黑紋，已移除重複上蓋，保留木質踏面。

證據：[初輪主視](iteration-1/blender/hero.png)、[同機位前後比較](before-after-blender.png)、[最終六視圖](six-views.png)。初輪為16 samples，最終64 samples；幾何、色彩空間及材質有實際修改，不能把差異只歸因於光照。

## 第二輪：實體構件、背面及玩家尺度

第二輪檢查八視圖：頁形輪廓、兩層實體立面與公共中庭保留，前後皆有完整框架。高窗薄玻璃投影成線時補5cm碰撞厚度，避免跳躍穿入封閉樓層；NPC旁花圃成組移出淨空。

實際檢視最終主視、正、背、左、右、俯視、建築近景、公共空間共八張 Cycles 渲染。`render-record.json` 的來源SHA與可編輯 .blend 及GLB模型報告一致；32張均來自真正模型，沒有AI圖。

遊戲證據：[QA全島](../game/H-hero.png)、[原生桌機](../game/H-desktop-native.png)、[正常旋轉後桌機](../game/H-desktop-facing.png)、[原生手機](../game/H-mobile-native.png)、[正常旋轉後手機](../game/H-mobile-facing.png)、[手機NPC預留區](../game/H-mobile-npc-reservation.png)。QA鏡頭和預設玩家鏡頭明確分開，不靠拉遠原生鏡頭宣稱可用。

## 具體限制與待人工驗收

閱讀館及STEAM館室內不開放；戶外階梯與中庭可用。沒有製作教育互動或課程，展頁意象與C島V3以上的主觀美術比較仍待使用者驗收。

自動測試驗證通行、碰撞與鏡頭取樣，不能證明所有人為觀察角度都完美，更不能替代文化詮釋、美術水準、真機發熱或長時間單手操作驗收。手機圖是Chromium觸控尺寸模擬，不是真手機硬體截圖。
