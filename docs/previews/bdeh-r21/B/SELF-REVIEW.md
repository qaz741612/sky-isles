# B｜環抱式長青生活院 R21 自主美術審查

這是工程與製作者自查紀錄，不是使用者美術批准。正式模型是本目錄 `blender/` 與 `docs/design/bdeh-r21/B/B-r21.blend`；`iteration-*` 是保留的歷史／失敗證據。

## 第一輪：量體與公共空間

保留雙翼曲線、中央療癒院與交流前廳。第一輪檢查主視、四立面與俯視，發現曲線翼樓端面封閉不足、樓層／屋緣不夠清楚，庭院樹冠與建築尺度脫節。

修正：補四處實體窗框端立面、連續樓層收邊、木質滴水緣及交流廳支承；放大原位置樹冠形成庭院遮蔭。依真正北／東公共走廊接入四個橋口，不讓道路穿過照護翼樓。

證據：[初輪主視](iteration-1/blender/hero.png)、[同機位前後比較](before-after-blender.png)、[最終六視圖](six-views.png)。初輪為16 samples，最終64 samples；幾何、色彩空間及材質有實際修改，不能把差異只歸因於光照。

## 第二輪：實體構件、背面及玩家尺度

第二輪同源八視圖已檢查：曲線雙翼、庭院和生活連廊仍是主體，側背面有相同窗框與屋緣。NPC完整3×3檢查發現樹幹侵入，已成組移位並重驗，沒有把樹刪掉或縮成盆栽。

實際檢視最終主視、正、背、左、右、俯視、建築近景、公共空間共八張 Cycles 渲染。`render-record.json` 的來源SHA與可編輯 .blend 及GLB模型報告一致；32張均來自真正模型，沒有AI圖。

遊戲證據：[QA全島](../game/B-hero.png)、[原生桌機](../game/B-desktop-native.png)、[正常旋轉後桌機](../game/B-desktop-facing.png)、[原生手機](../game/B-mobile-native.png)、[正常旋轉後手機](../game/B-mobile-facing.png)、[手機NPC預留區](../game/B-mobile-npc-reservation.png)。QA鏡頭和預設玩家鏡頭明確分開，不靠拉遠原生鏡頭宣稱可用。

## 具體限制與待人工驗收

室內未開放；沒有醫療或旅宿功能宣稱。庭院較安靜、展示較少，是否充分表達長青生活用途仍待人工判讀。

自動測試驗證通行、碰撞與鏡頭取樣，不能證明所有人為觀察角度都完美，更不能替代文化詮釋、美術水準、真機發熱或長時間單手操作驗收。手機圖是Chromium觸控尺寸模擬，不是真手機硬體截圖。
