# D｜開放式數位行政中樞 R21 自主美術審查

這是工程與製作者自查紀錄，不是使用者美術批准。正式模型是本目錄 `blender/` 與 `docs/design/bdeh-r21/D/D-r21.blend`；`iteration-*` 是保留的歷史／失敗證據。

## 第一輪：量體與公共空間

保留雙側服務廳與跨通道大型門廊。第一輪發現門廊端支承不清楚、服務入口較平、正側面的尺度提示不足。

修正：補實體屋頂承座、立面角柱、木鋼入口雨棚、柱列與三層低門檻。所有構件有厚度，跨通道底下保持公共通行，沒有用整塊碰撞盒封住門廊。

證據：[初輪主視](iteration-1/blender/hero.png)、[同機位前後比較](before-after-blender.png)、[最終六視圖](six-views.png)。初輪為16 samples，最終64 samples；幾何、色彩空間及材質有實際修改，不能把差異只歸因於光照。

## 第二輪：實體構件、背面及玩家尺度

第二輪檢查八視圖：跨通道屋架與兩側服務量體完整；入口屋簷、柱與階梯可辨識。NPC重新選在道路外側淨空，鄰樹移至邊緣，完整方形加.35通道餘裕稽核通過。

實際檢視最終主視、正、背、左、右、俯視、建築近景、公共空間共八張 Cycles 渲染。`render-record.json` 的來源SHA與可編輯 .blend 及GLB模型報告一致；32張均來自真正模型，沒有AI圖。

遊戲證據：[QA全島](../game/D-hero.png)、[原生桌機](../game/D-desktop-native.png)、[正常旋轉後桌機](../game/D-desktop-facing.png)、[原生手機](../game/D-mobile-native.png)、[正常旋轉後手機](../game/D-mobile-facing.png)、[手機NPC預留區](../game/D-mobile-npc-reservation.png)。QA鏡頭和預設玩家鏡頭明確分開，不靠拉遠原生鏡頭宣稱可用。

## 具體限制與待人工驗收

室內不開放，沒有新增數位服務系統。遠景仍有玻璃公共館的抽象性，服務用途需結合既有政策入口理解。

自動測試驗證通行、碰撞與鏡頭取樣，不能證明所有人為觀察角度都完美，更不能替代文化詮釋、美術水準、真機發熱或長時間單手操作驗收。手機圖是Chromium觸控尺寸模擬，不是真手機硬體截圖。
