# V5.1 第二輪模型自查（仍修正關鍵水工遮擋）

已檢視本輪同源主圖、水閘、指揮中心、俯視，與第一輪及原V5相同相機比對。

- 第一輪規則水格線已移除；新增明確入口花帶、嵌入式水循環標誌、連續前庭、入口/塔頂/側背立面細節，保留既有角色與路網比例。新增小構件倒角簡化後，面數由81081降至74615，仍60批次。
- 遠景主體、主入口、玻璃和屋面層次比V5完整；四面與俯視沒有草模背板。入口廣場保留真實活動淨空，兩條花帶及前庭銀行都已通過core/NPC/公共動線的幾何稽核。
- **仍未合格的關鍵問題：**出流區兩側牆頂目前固定高度，消能塊也露出水面過高，遮掉部分水位差，使近景仍偏像三道狹槽。下一步把內渠側牆頂做成隨水位下降的斜線，消能塊沉至近下游水位，增加少量不等寬的破碎中心白沫。保留厚度與結構，不動島面、橋面或水位。
- 不能靠改取景或只調燈光解決。以上將進入最後模型，再完整輸出最終視圖及真實遊戲畫面，補做手機與碰撞檢查。
