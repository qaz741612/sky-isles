# 測試執行環境診斷

受限沙箱曾讓Node子程序spawnSync回報status0但error=EPERM，npm測試因而只列20個檔名，不能當成71子案例執行證據。該次aggregate.log不列入驗收；改用允許真正子程序的執行設定重新執行npm run check。

另曾為取得子案例明細嘗試非標準單程序隔離關閉，70/71，只在此共享程序模式出現舊站房bounds案例失敗。該模式不是專案設定；不更改測試斷言，在正常獨立程序下重驗全部。保留診斷，不把兩次環境／不支援模式的結果稱為通過。run-flood-v5-units.mjs另明確拒絕子程序error及缺少案例數，避免EPERM假陽性。
