## 動線、碰撞與 NPC

- 舊 crystal 臨時造景透過 replacement 模式替換；原草地碰撞/岩體和重複鋪面不再疊在模型上。
- 原生橋面只在新島緣外；島內乾地由扣除水洞的實際三角面提供。原 4.8 通行核心保留，水邊防護外擴至 5.1，沒有跨橋口內欄。
- 地面、牆柱、門窗實體、座椅與花台、屋簷、攝影機外殼各自管理。前廊可走；玻璃立面封閉，沒有假黑門洞誘導玩家進入未完成室內。
- 屋頂、設施頂面與柱腳可支承刻意跳躍，但不成為安全重生檢查點；乾地仍可更新檢查點。
- 公共環線可抵達兩入口、前廊、水閘旁、池畔與兩個 NPC 預留區，不需跳躍。樹木與家具是可繞行的實體，不為通過測試移除碰撞。
- NPC 1 本地 (-9.5,0,1.0)，面向 +π/2；NPC 2 (8.7,0,-3.1)，面向 -π/2。各有 3×3 空間、建議互動半徑 1.65；沒有 NPC 身體、對話或任務。原小矩形預留已標示 superseded，不能當本園區尺寸限制。
- 世界聯集只產生真正外欄；G 由 Blender 顯示這些同座標護欄，遊戲原生橋欄不再重複顯示。內部水邊欄杆對應可見邊界。

## 模型與成本

GLB：**42,773 三角面、33 批次、17 材質、0 外部貼圖、2,342,896 bytes**。原生兩塊柱腳另加 24 三角面/2 mesh。可編輯 Blender 包含 1016 個獨立 mesh 構件，依邏輯組分層，匯出才依材質合批。沒有新依賴、每燈光源、流體模擬或每幀重建模型。

GLB SHA256：`758833dc90065fed371a6e854f560c68b6e790e05008a4021febb28c43c9059b`。

同源 Blender SHA256：`21a19f97ae9e2a8010efc0ea84646d7e3b3e17c0bffcc67ca5a0a02750038391`。Cycles CPU、48 samples；環境無 OpenImageDenoise，已明確停用，不使用 AI 補圖。

本機新版 GLB 桌機下載 130.0 ms、解碼 13.7 ms、建構 29.6 ms；手機尺寸下載 110.6 ms、解碼 12.3 ms、建構 7.4 ms。這是 localhost/共享執行環境，不代表 WAN 或真機載入。

GPU 是 **SwiftShader 軟體渲染**。Draw Calls/三角面為實際 renderer 計數，透明與既有透射材質會重複送出場景；不能當唯一模型面數。firstFrameSubmissionMs 只量到主程式首次提交影格，不保證 GPU 完成或實際首次可操作。**真實桌機/手機 FPS、發熱、記憶體壓力、長時間單手體驗與真實網路載入均未驗證。**

## 尚待人工驗收與限制

- P0/P1：本輪最終自動化安全/連通測試沒有已知未修復失敗；這不等於完整人工驗收。
- P2：與概念圖的景觀密度、建築氣勢、木石質感及遊戲接地光影仍有差距；請逐圖審查。手機原生鏡頭可探索，不保證整座約 28×26 園區同框；完整構圖使用 QA/全景，不能將 QA 圖冒作玩家預設。
- 未驗證：真機效能/發熱、長時操作、所有 orbit/zoom 的遮擋組合、苑字一眼辨識度。
- 未實作：NPC、室內登塔、閘門操作、流體水文模擬；列為非本輪可用功能。水是低成本靜態材質與流線示意。
- 已驗證一般步行防護；刻意跳躍/滑翔越過欄杆仍可能落水/離島，使用原安全復位。沒有宣稱完全無法越界。

```sh
node scripts/build-flood-site.mjs

blender -b -t 4 --python scripts/blender/build_flood_g.py

npm test

```
