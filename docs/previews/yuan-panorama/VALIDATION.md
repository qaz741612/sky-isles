## 自動化實際涵蓋範圍

### 地面、護欄與連通

- 21 個圖節點、22 段曲線與八座政策島形成同一網絡，實體 Boolean union 只有一個連通分量。
- 使用真實 Player、島面、合併步道與交通島既有碰撞面，在 `dt=1/60`、`dt=0.05` 各走過全部 22 段路線雙向，禁止跳躍，未跌落或復位。
- 額外驗證所有有多個入口的節點，共 **76 種有向進出轉向**，含交通島、J1、J2、曲線銜接與其他島嶼，無內部護欄阻擋或地面接縫卡住。
- 逐一檢查實際 Float32 碰撞三角面，非退化且最大坡度 **0%**，低於 10% 目標。本輪採水平共用基準，沒有拿中心線坡度代替三角面驗證。
- 所有有效外邊界護欄的碰撞座標，直接用於可見護欄生成；對長度至少 0.05 的 **1,691／1,721** 個邊界片段雙側執行穿越阻擋測試。更短的數值切分片段仍包含在正式碰撞與渲染資料內，透過路口／整線通行測試涵蓋。
- 近零 X 軸沿島面三角扇形邊緣移動的回歸測試：不再因單點射線漏判而穿過地面。
- 放開搖桿後停止距離有上限；站上蘑菇但未按跳躍不會自動彈起。
- 在非起始安全位置強制跌入虛空，回到最近已驗證檢查點，不固定回起始島；瀏覽器亦驗證遠處政策島的跌落復位。

### 瀏覽器、單手操作與政策功能

- 桌面 1440×900 與 Chromium 模擬 iPhone 15 Pro Max（430×739 CSS 像素，DPR 3）。
- 原生鍵盤／原生 CDP 單指觸控建立輸入與 pointer capture，再於同一個瀏覽器 task 中以同一 pointer 的 DOM move 事件、既有 UI.poll 與真實 Player，固定 dt 加速走過全部路線。
- 這是加速的單指輸入整合測試，**不是一位真人持續握手機的完整走訪錄影**。自動化不會模擬真實手指疲勞、裝置發熱與各手機 GPU 的幀率。
- 原生單指 touchEnd／touchCancel 會清空搖桿輸入並停止；移動期間鏡頭 yaw 保持穩定。
- 八個政策視窗、空內容占位與交通場景示意聲明、標籤點擊、Escape、收合選單、教學關閉、手機控制區、鍵盤方向、跳躍、旋轉、縮放、相機跟隨及 favicon 回歸。
- 車站、列車、鐵道及原有道路保留；原有道路橋最小平移後，新西向入口已納入真實控制器通行與所有路口轉向測試。沒有新增另外七島主題模型。

### 全景與返回

- 點擊一般 UI 的「全景」，平滑鏡頭位置、旋轉與投影，最終使用真正的 OrthographicCamera。
- 全景期間暫停 Player 更新與移動輸入，隱藏政策選單、政策標籤、操作提示和觸控按鈕；關閉雲霧遮擋，保留實際地形與建築。
- 對真實路網外框四角投影檢查，桌面與手機直式均完整落在畫面內；單元測試另涵蓋 320×568、844×390 等尺寸。
- 進入全景後按移動鍵不改變人物位置；返回不重置座標、orbit、檢查點或風鈴進度。
- 返回後仍可開啟政策介紹。
- 五張 PNG 在瀏覽器測試中從同一真實場景截取，沒有把設計 PNG 加到畫面裡。

## 尚待人工驗收／已知限制

1. **字形美術辨識度**：請先看不含政策標籤的 `panorama-pure.png`，再在網站進入全景，判斷是否能直覺讀作手寫「苑」。自動化只能證明實體幾何、攝影機與完整構圖，不能代替人的中文字辨識。
2. **實機流暢度**：目前是 headless Chromium／軟體 WebGL，不代表 iOS Safari、Android 真機、低階 GPU、電量與溫度情況。沒有宣稱達到特定 FPS。
3. **單手手感與鏡頭舒適度**：請真人握持手機，走過長斜撇、各路口、右下彎鉤，評估視角跟隨、放手停步與切換暈眩感。
4. **所有島面採 `y=0`**：保留浮空岩體與造型，但本版放棄方案 A 的 0–2 高低差，以確保整體平穩連通。若未來恢復高低差，須重新處理路面內部三角化與坡度，生成器目前會拒絕不同高度節點。
5. **島嶼懸崖仍可跌落**：新步道雙側與端部有護欄，島嶼整圈並未新增護欄；誤走島邊時依最近安全點復位。既有交通模型大部分仍是裝飾物，沒有擴充成完整建築實體碰撞系統。
6. **中心線距離不是任意面上的測地最短距離**：路網比較採 21 節點／22 邊的弧長最短路；寬廣島面或路口可略微抄近路。
7. **公開 Preview**：沒有合併 PR、沒有修改 Cloudflare Production 分支或部署設定，也沒有主動呼叫發布指令。GitHub 推送／PR 可能依既有 Cloudflare 設定自動建立公開 Preview；本環境沒有 Cloudflare 專案設定讀取介面，不宣稱該自動行為已關閉。
