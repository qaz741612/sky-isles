# 實際遊戲效能：CPU 軟體 GPU 測量

**本環境的整合版不流暢，不能宣稱效能驗收通過。** 真實桌面顯示卡與手機硬體 FPS 尚未測試。

## 環境與方法

- Chromium，ANGLE Vulkan SwiftShader（CPU 軟體繪圖）；CPU quota 2 核、記憶體上限 8 GiB。沒有硬體 GPU。
- 原版：PR #11 最新程式 `ac433fd5d23f00d3aab9470d96349114e1a37b24` 的正式建置 `index-CvzgTfWg.js`。整合版：正式建置 `index-9F6Uh_WJ.js`。
- 每個案例新 browser context，八島全世界載入，玩家定位在同一親子島前庭本地 (1.1,5.5)，沿用相同預設跟隨相機。原版在此處是舊程式親子館。
- 桌面 CSS／canvas 1440×900、DPR 1。手機模擬 CSS 430×739、canvas 645×1108，裝置 DPR 3、遊戲既有 cap 1.5；不是 iPhone 真機。
- 2.5 秒＋10 個實際渲染 frame 暖機後，用真實 rAF 間隔測量至少 12 秒／6 個間隔。整合版因低 FPS 實際樣本超過 12 秒。**遊戲、GPU、動畫與物理正常運行，未停用 renderer、改 dt 或以工程步進換算 FPS。**
- 量測期間沒有其他瀏覽器、渲染、建置或測試工作。前後順序與原始資料完整保存在 [performance.json](performance.json)。這不是跨機器可重現的硬體排名。

上述 calls／三角面是**指定前庭鏡頭下實際繪製的世界**，含玻璃 transmission 的額外 pass，不是模型原始面數，也不是只載入單一 GLB 的孤立測試。其他七島仍在世界中，正常 frustum culling 生效。

`loading 隱藏` 是本機 HTTP 首次程式載入、模型解析、建構及第一輪 render 提交的時間；沒有等待第一張 GPU 畫面完全完成所有光柵與後續 GPU 暖機。因此不能把約 2 秒這個數字宣稱為手機使用者看見流暢遊戲的時間。原版與整合版的 loading 時序／shader 組合也不同，不以此宣稱整合版載入更快。

## GLB 與記憶體

- 原檔 20,239,060 bytes、380,999 三角面、207 網格、29 材質；無外部貼圖。
- 同一個 GLB 在遊戲中保留建築／室內／遊具／景觀及平台，展示橋臂／展示欄杆改由實際路網銜接後為 **356,223 三角面、60 個渲染網格、786,272 頂點**。
- 同材質不透明構件按語意區合批，玻璃保留原構件排序；保留索引比一律展開三角面少 26.4% 頂點。沒有幾何降面、材質替換、重建屋頂或模型縮小。
- 桌面 JS heap 觀察約原版 20 MB→整合 96 MB；手機模擬約 25 MB→91 MB。這是 Chromium 近似 JS heap 快照，包含原始模型與代理資料，不能當作完整 GPU／系統記憶體。
- 本機 GLB HTTP 原始傳輸 20.239 MB；桌面 resource 約 185 ms、`loadAsync` 約 238 ms、建構約 398 ms；手機模擬約 148／204／321 ms。未模擬慢網路，不是手機行動網路下載時間。
- 增加的紋理主要為陰影及 transmission 渲染目標；模型本身沒有新增圖片貼圖。

## 已採用且不改核准外觀的處理

1. 保留原始索引與同材質合批，減少 CPU 上傳與 Draw Calls；只按本島／語意角色合併，不合併整個世界。
2. 建築／地面／相機代理空間分塊，護欄使用既有空間索引。靜態資料只在載入時生成，列車仍走既有動態更新。
3. 使用既有方向光的一張 1024 陰影圖，首次更新後固定；其他七島不接收新陰影，沒有新增即時光源。
4. 比較過半解析度玻璃但窗面模糊，因此**未採用**；最終 transmissionResolutionScale=1，原材質 29 組參數與來源一致。

## 建議下一步，尚未套用

先由使用者在 Preview 用真正桌面 GPU／iOS／Android 測量，分別記錄近景、廊下與全景，持續操作至少 10 分鐘看發熱與相機手感。如果真機也不符合目標，優先做不改美術的載入／記憶體及 draw-call 分析：釋放已合批的原始 scene 參照、檢查伺服器傳輸壓縮／快取、評估 lossless mesh buffer 壓縮與分區延遲載入。

若仍需降低玻璃成本、製作距離 LOD 或合併更細的景觀幾何，應先提供與核准原版相同鏡頭的比較再確認；本輪**沒有擅自降低玻璃解析度、刪掉家具／植栽、改顏色或生成替代模型**。

這份結果證明功能及資產能在真實 Three.js 遊戲中運作，也揭露 CPU 軟體 GPU 的成本；它不能證明真機 FPS、發熱、長時間舒適度或人工美術驗收已通過。
