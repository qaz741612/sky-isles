# 苑裡政策島 — 交通大升級島｜高架車站建築美術執行規格
**狀態：設計方向已核准，幾何布局已完成初步驗證；最終美術尚未過關。本檔是 Blender 高精修製作規格，不代表模型已可上線。**

## 一、單一設計目標
把本包的 `美術參考_高架車站.png` 轉成「同一套可旋轉、可檢查、可在 Sky Isles 使用的 Blender 原始工程與 GLB」，**不得重設計成簡化版**。風格為幻想式、微縮但非積木式的現代臺灣高架鐵路小站，具有玻璃與暖木混搭的站房、上層輕量化高架月台、可辨識列車、門廳識別、旅客休息區、濃密而分層的園藝景觀。此島不是苑裡真實站區 GIS 重建，也不需要真實比例 1:1。

### 第一優先：看起來就是同一座建築
- 45° 主視圖：必須同時看見**有圓弧端部與清楚列車車窗的車頭、上層雨棚、下層玻璃木質站房、入口標誌、完整站前花園**。
- 高架與站體要一體構成：高架橋柱／拱、下層站房、樓梯與電梯視覺上互相協調，不是橋架到現成盒子上。
- 上層雨棚有**真正的屋簷厚度、縱橫肋架、局部透光天窗、木質底板、金屬收邊與照明**，切忌把幾塊平板直接貼在柱上。
- 站房應有明確主入口量體，入口的地坪、深檐、立柱、玻璃、木格柵與識別牌要形成一個構圖焦點。站體正面可用 **「臺鐵｜苑裡站」** 或概念示意「鐵路局」字樣，但不要複製未提供之官方受保護 LOGO，也不能誤以為這就是現實的站改建計畫。
- 地面前場採「兩側濃密植栽 + 主入口清楚空間 + 可辨識中央步行軸 + 幾處群聚休憩座位」，**不允許隨機灑四棵圓樹加大片空地**。樹高有層次、花台有連續性。

## 二、已驗證的世界座標與比例（建模起點，不是禁止小範圍建築優化）
- 座標：x 向東，y 向上，z 向北；交通島中心 F=(0,0,0)。玩家身高基準 1.5 世界單位；原出生位置 `(0,0.5,3.5)`。
- 島台外接尺寸 **20.33 (x) ×19.82 (z)**；V9 不規則地界在實際 GLB 中。若為還原核准圖確有必要，可提出調整島台輪廓；但不得自行變更路網中心線或「苑」字整體辨識。
- 高架橋範圍 x **[-9.45,+9.45]**，南北約 z **[-9.35,-5.98]**；高架月台約 y **3.75**；底部淨空約 **3.29**；列車頂約 y **6.21**；月台棚最高約 **6.79**。
- 一樓站體 x **[-6.85,+6.85]**，z **[-5.79,-3.04]**；站前主要視野與道路在 z>-2.5 區域。
- 電梯大致落在 x **[6.80,8.60]**、z **[-5.30,-3.58]**，折返樓梯在 x **[-9.15,-6.90]**、z **[-7.50,-3.07]**；上下層連接不能省略。
- 兩 NPC 互動預留中心 `(-3.70,3.93)`、`(+3.65,3.93)`；各須空出地面 **3×3** 區域（裝飾不得占用必要碰撞空間）。
- 四個接島連結 **S09、S10、S15、S18**，寬均 **4.8**；是核心保留線。原始路網資料讀取 `src/data/yuan-plan.json`，不能只憑圖片畫道路。

## 三、七個必須精修的建築部分
1. **下層站體門廳**：加深入口門框及雨棚，門窗有玻璃分格、地面售票／閘機／服務區，室內保持可透視的暖光；真正修飾比例，不要加一堆無關裝飾。
2. **高架橋結構**：具有結構邏輯的橋面、成列橋柱、適度輕量化拱／梁、上下游側面立面層次；兩側護欄、橋下視線與道路凈空須成立。
3. **上層月台雨棚**：主鋼骨、木底板、玻璃採光帶、檐口轉折、柱接頭、暖色帶狀照明；做到 45°／立面／背面各視圖一致。
4. **兩節列車**：車頭圓弧與前檔玻璃、門窗比例正確、車門接縫、下盤轉向架與軌道位置真實對應。列車必須成為遠處可讀出的交通地標。
5. **垂直動線**：左側實體折返樓梯，右側玻璃電梯塔與月台連通，不可虛構只看得到卻到不了的通廊。若因遊戲跳躍／膠囊碰撞限制需簡化，應在 QA 說明。
6. **站前鋪面與景觀**：地磚分區、行走軸線、燈柱、候車長椅、花台與喬木根部整合；植栽採材質／實例化優化，鏡頭近處精緻、遠處簡化。
7. **浮島地形**：不要統一厚度的圓盤展示台；島台外緣採岩層、人工護欄、路基、階梯平台等不同邏輯的過渡；不得破壞與道路銜接。

## 四、材質與氣氛規格
- 主屋頂：低彩度藍灰色金屬，清楚的立體縫線、不同反射粗糙度與檐口。參考灰藍 `#778A9B`。
- 構架及護欄：深藍綠 `#3B7180`、暖灰鋼 `#667D82`，配合金屬 PBR。
- 站房：暖木 `#C08B55`、柔和石色 `#D4C9BC`、半透明玻璃 `#9AC6D1`；玻璃不是平塗的藍灰方塊。
- 列車：暖白 `#E6EDF0`，藍綠交通條帶 `#3B8699`，少量黃色 `#E8BF68` 作辨識重點。
- 照明：白日漫射暖陽 + 入口暖光 + 高架底間接照明。維持與七島認可美術圖同一世界的暖色遊戲質感。
- 綠植：樹冠應有大小、層次、枝葉密度；大花盆與矮灌叢群聚，嚴禁一堆一模一樣的球狀灌木。

## 五、重要的品質警示（V8/V9 敗因）
- `F_elevated_station_v9_design.glb` **是精確幾何尺度代理**，不是美術範本；它以程序化 primitive + 無貼圖顏色製作，質感僅供測試尺寸，不可照外觀原樣精製。
- 最重要的**樣貌來源是 `美術參考_高架車站.png`**；幾何尺寸與路網限制以現有 V9 GLB + 驗證 JSON 為準。兩者若有衝突，優先改變建築量體或局部島台，不能暗中縮小列車／砍掉花園等犧牲美術的方式達成。
- 不能從那張 AI 圖直接擷取「假背面」或用視角修圖冒充六面模型：所有視圖必須從 Blender 同一個完整建築場景輸出。
- 不允許用既有 `k.hall()`、統一弧屋頂模板，或複製安心生養島的建築語言。
- 已核准的安心生養島 GLB/路網/拼圖及玩家功能應保持不變。

## 六、正式交付（建築原型階段，不要擅自整合到正式遊戲）
1. 源 Blender `.blend`，單位、物件群組、可替換材質、碰撞代理清楚；有可調整的燈光與材質。
2. 正式展示用 `.glb` 與較輕量化的遊戲候選 `.glb`；包含實用型碰撞殼清單。
3. 同源 **45° 主視圖、正面、背面、左側、右側、俯視、列車側主視圖**，以及符合 Sky Isles 桌機 camera dist16/pitch.60/fov55、手機 dist22/pitch.67/fov58 的**模擬**鏡頭。模擬不能冒充 Three.js 實測。
4. 站房尺寸表、四個橋口與 NPC 清空區、模型三角面／材質數／GLB 體積報告。
5. 對比核准美術圖的差異表，列出每一處尚未重現的特徵。正式整合前必須完成真正遊戲內的跳躍／碰撞／遮擋／效能驗證。

- 審核重點：建築造型25、場景構圖20、景觀15、主題辨識15、比例與遊玩15、同源幾何10，共 100。
- **90 以上且無重大缺陷才進入正式整合評估**；分數是內部美術審查，不能取代實機檢驗。
- 任何不通過的版本由製作端自行修改；禁止把不及格的渲染當完成品要求使用者反覆批准。
