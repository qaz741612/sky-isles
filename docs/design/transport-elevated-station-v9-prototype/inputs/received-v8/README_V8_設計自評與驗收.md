# 交通大升級島｜V8 高架鐵路交通驛站（設計審查包）

設計目標：將交通島從 V7 平面站，升級為「上層高架列車、下層站房」的一體化交通驛站。設計參考是使用者認可的 AI 高架站效果圖；正式檢驗視圖來自單一 GLB 幾何來源（不是六張分別生出的 AI 圖）。此包沒有修改 Sky Isles 正式遊戲或原有安心生養島。

## 幾何資料

- 島台 x/z 約 **20.33 × 19.82** 世界單位，非正圓，中心 F(0,0)。
- 島台外接座標：[-10.164, -11.17, 10.17, 8.649]；面積 333.79 平方世界單位。
- 地面道路維持 4.8 寬。四條接線分別 S09、S10、S15、S18；原本「苑」字路網中心線未修改。
- 地上站房主體 x [-6.85,6.85], z[-5.79,-3.04]；面向北側玩家入口。
- 高架平台高度約 **3.75**，下方淨空/橋底約 **3.289**（高於 1.5 人物）；列車頂約 6.208，整體棚架約 6.79，整體模型最高約 6.84。
- 四個柱列（兩排），柱座位於站後側，不插入既有橫向道路。
- 兩端分設折返樓梯、玻璃電梯及月台連接段，幾何存在，但樓梯跑跳碰撞及導航未進引擎實測。
- 正面設計文字為「鐵路局」「苑裡站」，象徵性識別圖不是正式政府企業 LOGO，僅作概念示意。
- NPC：[[-3.7, 3.93], [3.65, 3.93]]，各保留 3×3 空間，並檢查整塊不與平面障礙相交。
- 原玩家出生位置 (0, 0.5, 3.5) 未修改。

## 已執行幾何檢核

- 站房、高架結構、電梯與樓梯平面包絡均位於此島地界內。
- 對照 S05/S08/S11/S02/S07 其他筆畫之道路 4.8 寬：交疊面積均 **0**。
- 與已核准的安心生養島半徑 10.2 模擬地界：交疊面積 **0**。
- 東西道路原 4.8 寬範圍內無地面實體障礙，交疊面積 **0**。
- S09、S10、S15、S18、spawn、站房正面、電梯外、樓梯外與 NPC 均在同一組地面網格連通元件；網格精度 0.14，障礙額外留 0.34 的人物避讓距離。
- 立體模型以 trimesh 重新載入成功，具有 87 組幾何節點，約 28,328 個三角面，GLB 約 0.76 MiB。

## 尚未通過的關卡（不宣稱已能直接上線）

1. 建築模型的 PBR 材質、玻璃通透、夜間暖光、繁複綠植，仍無法與高品質美術參考達到同等程度。這份 GLB 是實際尺度／構造／相對關係設計來源，不是已完成的最終遊戲美術品。
2. 已依公開 Sky Isles 既有桌機 camera dist16/pitch0.60 與手機 dist22/pitch0.67 做獨立相機透視模擬；上層棚架接近畫面頂端，行動版橫幅可能受到視野裁切，需整合引擎後確認是否採交通島特殊建立鏡頭。
3. 平面網格通過，不能代替 Three.js 動態膠囊碰撞、階梯爬升、欄杆、屋簷遮擋與樓梯實際 navmesh。
4. 無修改實際 repo，沒有通過 WebGL 整合與效能壓力測試；正式移植前須以真實 8 島全景再確認「苑」字辨識度。

## 檔案用途

- `交通大升級_V8_高架車站_美術工程對照.png`：美術品質目標與真實幾何落差。
- `交通大升級_V8_高架車站_同源六視圖.png`：同源 3D 工程視圖，非 AI 多角度假合成。
- `交通大升級_V8_真實尺度與橋口.png`：橋口、站房、高架、雙 NPC 與通道配置。
- `F_elevated_station_v8_design.glb`：可旋轉檢查的實際模型。
- `V8_工程檢核.json`, `V8_自動檢查結果.json`：檢驗數值。
- `build_transport_v8.py`：可重現幾何與圖面；使用 trimesh / shapely / VTK。
- `views/`：九個真正取自同模型的視角；桌機與手機是引擎相機參數的獨立模擬，不是遊戲實機截圖。
