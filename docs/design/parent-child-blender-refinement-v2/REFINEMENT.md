## 版本來源

本輪開啟 PR #11 的 `docs/design/parent-child-blender-model-v1/parent-child-centre.blend` 後修改。基礎提交 `a3474c26c81ce826090c491fec94a8e615a69271`；原 BLEND SHA256 `24a45378caa981ef6b69de1650424ef98aa9d39fe5ad09f8809e68955536b86f`。第一版模型與圖片保留原路徑，第二階段位於本目錄，方便追溯。沒有從 V1～V3 的簡化模型重做。

## 建築

- 主弧頂與上層採光屋頂：以端部平順過渡的曲線修整原網格，主弧起拱參數由 1.65 降至 1.45，上層由 0.65 改為 0.58；同步調整簷口、木肋、弧形窗面與上窗框。不是只改屋頂、留下不貼合的立面。
- 主屋頂及上層可見長向分割線由 24 條降至 8 條，線寬約 0.025→0.012，名義間距 0.43→1.1；低翼分割線亦減少。取消中間橫接線，保留有厚度屋面、收邊與屋底。
- 材質減低金屬度、降低分割線色差，提高屋面粗糙度，避免整片鋼板反光。沒有換成新的建築風格。
- 左翼前後立面間深度 3.15→4.45，右翼 3.10→4.30。既有窗、基座與屋頂連同深化，後方書架移至更深房間。
- 新增西側約 1.12、東側約 1.05 寬的半戶外廊道，薄實體雨棚、木柱、簷底肋條及地台分件。廊道開放，沒有用整塊碰撞盒封門。
- **原有入口木雨棚、家庭拱牌及入口側木格柵的幾何位置與形體保留**；木色略調整以統一材質。

玻璃採真正 PBR transmission 1.0（原 0.82）、roughness 0.045（原 0.14）、IOR 1.45；保留玻璃幾何厚度。增加合理傳輸反彈及略調室內燈色，讓既有實體桌椅、沙發、書架看得見。沒有以內裝貼圖或無厚度平面冒充室內。背面渲染檢查後，另將七片書櫃背板改為開放背架，保留側板、層板與書本，避免背窗後整塊暗面；上層室內燈由 4.35 降至 4.12，修正弧頂調整後燈面藏進屋頂的遮光問題。從特定斜角仍會反射環境，未把玻璃做成全消失材質。屋簷仰視近景仍可看到明顯柔光源反射；主視角的通透性改善不代表所有角度都無反光，這仍待人工接受或後續調光。

## 親子活動與景觀

- 原有小屋、曲面滑梯與低橋保留，組合向廣場左前方微調，主視角可辨識。
- 新增 0.8 高左右的木質拱形低攀爬架，具圓桿、橫檔與繩條；配色沿用暖木與淡綠／淡藍／沙色。
- 軟地面擴展至約 7×4.9，涵蓋滑梯落地與低攀爬區；沙坑另保留獨立邊框與玩具。
- 新增正常尺度的照顧者長椅，面向遊戲場。花台轉至不妨礙進出的邊緣，而不是往動線繼續堆物件。
- 保留四棵樹與原樹池。葉團做輕量細分與非對稱修整；西側樹移開新廊道及入口，右樹調整位置／冠幅，避免穿過新增雨棚。
- 木材使用較自然的色階與粗糙度，維持 GLB 可用的純 PBR；未新增貼圖或不能轉出的複雜程序材質。
- 平台及鋪面依原生成器擴至半徑 10.2；增加範圍內的完整鋪面，保留原有淺石色分塊、收邊、四橋口與開口欄杆。

## 土地、入口與 NPC

平台由半徑 9.2→10.2，新增約 60.95 平方建模單位（+22.92%）。增加空間用於建築縱深、開放側廊、父母座椅與通道分離，沒有把建築或人物整體縮小。

入口保留原四方向。先依景觀與建築設計路線，再用實際模型幾何檢查，發現西側燈柱、低樹冠、西南花台及攀爬架的局部衝突後，修改物件位置與轉向；沒有以自動找空地取代設計。

四入口到門廊的 1.2 寬通道在最終保守包絡檢查下無幾何重疊；0.35 半徑玩家中心線也無碰撞。門廊路線止於玻璃門前，不穿越玻璃。NPC 活動區與四條通道分開；保留單一主要站位，無 NPC 模型／對話系統。

座標定義為 Blender Z-up；GLB Y-up 轉換為 `(x, y, z) → (x, z, -y)`。NPC Blender `(-0.2, -3, 0.03)` 對應模型 GLB `(-0.2, 0.03, 3)`。這些是**模型局部座標**，日後整合再依島位置變換，不是直接寫入遊戲世界。

## 視覺與工程限制

1. 玻璃反射與室內亮度受光源及觀看角度影響；WebGL 光照與 Cycles 仍不同，不能保證直接匯入遊戲就與離線渲染一致。
2. 樹冠比第一版圓潤，仍為分團構成的風格化樹；美術是否更合意由人工比較，不宣稱主觀品質已通過。
3. 新半徑只用於獨立模型。未變更遊戲島半徑、橋線、入口與其他七島；模型橋口尚非現場路網對位成果。
4. 玻璃門為關閉幾何，室內家具供可視層次；尚未提供門動畫、室內漫遊或遊戲碰撞控制器。
5. 空間稽核以指定身體高度與保守凸包進行，不能代替相機、跳躍、真實碰撞三角面、地面接縫或無障礙法規驗證。
6. GLB 約 38.1 萬三角面、207 批次，仍為高精度測試資產；本輪沒有破壞外觀式降面或聲稱真機效能達標。
7. 原參考圖不可見的背側面與室內仍是 PR #11 延伸設計；本輪以八視角問題修正為目標，不宣稱原作者背面設計還原。
