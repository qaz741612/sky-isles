# 苑裡政策島｜BDEH R20 — 實際幾何與自我審查

## 文件狀態
本包為本輪實際重建結果，不是 AI 概念圖，也不是正式可部署成果；R18 原建築沒有直接貼上細節，而是各建築重建新的源幾何。

**工程預檢通過**：四島尺寸固定 B30×28、D32×29、E34×31、H33×30。依 R18 提供之候選內部道路模型，4.8 單位通道與建築包絡、屋簷越界的離線 2D 平面檢測結果為 0 筆違規。

**重要未驗證**：離線候選內部路徑不是正式 Three.js 22 段 Bezier 動態生成後的完整路網；未在遊戲裡驗證所有橋口/碰撞/遮擋；未在真實手機測試操作和 FPS；沒有 Blender .blend，GLB 為 trimesh 程序化生成。不能宣稱已超過 C V3 的美術標準。

## 真正重做的建築
- B 幸福養老：兩層實際環抱式建築、雙側連續玻璃立面、徑向木構與多層天花、實體入口公共廊、半開放療癒內庭。避免 R18 單層曲簷上蓋簡單方盒。
- D 智慧公所：開放式兩層樓板、四面玻璃公共服務廳、雙片大跨度屋翼及三角支撐、整合式天光中庭、前入口遮陽構架。取消大型一般辦公盒。
- E 宜居環境：刪除 R18 的綠色平台堆疊，改為從低處上升至高處的單一連續地景曲面、雙翼天窗、實際樓層和木構承重、整合雨水花園。禁止重做溫室或額外瞭望塔。
- H 教育發展：完整雙翼兩層玻璃學習中心及承重結構、雙書頁曲面與肋骨、連續學習中庭、戶外低層學習階梯。避免只有特殊屋頂。
