## 高度插值與水平交會

令 s 為路段弧長，L 為總長，a/b 分別為 JSON 的 flatFrom/flatTo。前 a 與末 b 長度保持端點高度；其間令 `u=clamp((s-a)/(L-a-b),0,1)`，高度為 `y0+(y1-y0)*(3u²-2u³)`。最大中心線坡度為 `1.5*abs(y1-y0)/(L-a-b)`。兩端同高度的路段全段水平。
