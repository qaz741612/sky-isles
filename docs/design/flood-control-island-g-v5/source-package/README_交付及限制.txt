G 治水防災 V5｜擴島大型水利園區（設計模型，不是已上線遊戲）

這份是真實幾何/GLB/多視圖的可重建設計。檔案不是 AI 單角度美圖；但也不是已與 Sky Isles 正式碰撞整合的成品。其最終遊戲美術與真機效能須由 Codex 對照現有 PR #17 施工並驗收。

設計發現和處置：
1. 舊版 28×26 島面塞不出理想水利主體，重新設計為原中心約38.4×34.4不規則 G 島。
2. 與其他政策島換位並沒有比原址擴大更好。對原苑字路網的初步檢查：不相連 S20 與新島面路芯仍有約4.1單位保守餘裕；H最近島面尚約17.1單位區隔。
3. 第一輪水塘被地層遮蔽、硬體渲染黑影格，已調整乾地真水洞並改用可重現軟體深度渲染；不存在用無法重建 AI 圖替換的情況。
4. 第二輪發現 S22 穿越新水域、舊 water-guide NPC 站位落水、指揮中心局部壓島緣，分別加入跨水結構、移到乾地(10.2,-9.1)、重新收縮建築局部包絡與保護路面。
5. 第三輪發現上游水域一角超出島體，已強制裁切並留至少0.9單位島緣護岸；靜態幾何檢查已清空越界、NPC 占水與建築壓道路核心問題。
6. 模型立面、三閘、獨立機械閘葉、維修棧橋、指揮中心、觀測塔、雙水系、景觀堤岸來自相同可重建幾何；六視圖是同源畫面並裁切放大方便審查。

重要：因為擴島動到水洞及 S22 路基，不能沿用舊 G V1 碰撞證據。本包只完成設計幾何與部分 2D 空間稽核，不代表玩家可以正式通行，更不代表手機 FPS 合格。
